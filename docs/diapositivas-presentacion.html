📋 Acto I · El Problema Real | Contexto de Producto (R6, R9)

🎯 El Dolor del Usuario: ¿Por qué fallan los portafolios actuales?

❌ Fricción en Soluciones Tradicionales

  • SPAs sobrecargadas de JavaScript: Descargan entre 300 KB y 1 MB de runtime solo para mostrar texto estático en móviles 4G.
  • Contenido Markdown frágil: Sin contratos de datos, una fecha inválida o portada faltante rompe la interfaz en producción.
  • Accesibilidad y SEO secundarios: Bajo contraste en modo oscuro, parpadeos de tema (FOUC) y ausencia de sitemap o RSS.
  • Formularios desprotegidos: Validación limitada al navegador o dependencia total de servicios cerrados de terceros.
📉 Costo real: Más del 53% de usuarios móviles abandona un sitio cuando tarda más de 3 segundos en renderizar.

💡 La Oportunidad Product-First

  • Primera prueba de ingeniería: Un portafolio técnico demuestra criterio arquitectónico ante reclutadores y clientes en los primeros 3 segundos.
  • Plataforma dual unificada: Integra vitrina de proyectos, credenciales con CV descargable y un blog técnico de 10 artículos.
  • Cero desperdicio de recursos: Entrega HTML estático instantáneo en lectura y activa JS o servidor únicamente donde agrega valor real.
🧠 Regla de Oro: “A nadie le importa cómo construiste el motor hasta que primero siente qué tan rápido y suave viaja el automóvil.”

src/content.config.ts 
import { defineCollection } from 'astro:content';
import { glob } from 'astro/loaders';
import { z } from 'astro/zod';

const blog = defineCollection({
  loader: glob({
    base: './src/content/blog',
    pattern: '**/*.{md,mdx}',
  }),
  schema: ({ image }) =>
    z.object({
      title: z.string(),
      description: z.string(),
      pubDate: z.coerce.date(),
      heroImage: z.optional(image()),
      tags: z.array(z.string()).default([]),
    }),
});
export const collections = { blog };

src/components/BlogFilterIsland.tsx 
const filteredPosts = useMemo(() => {
  const query = searchQuery.trim().toLowerCase();
  const isFiltered = selectedTag !== "all" || query.length > 0;

  if (!isFiltered && initialPosts?.length) {
    return posts.filter((p) => initialPosts.includes(p.id));
  }
  return posts.filter((post) => {
    const byTag =
      selectedTag === "all" || post.tags.includes(selectedTag);
    if (!byTag || !query) return byTag;
    return post.title.toLowerCase().includes(query) ||
           post.description.toLowerCase().includes(query);
  });
}, [posts, selectedTag, searchQuery]);

// src/pages/robots.txt.ts — Fuente Única SEO
import type { APIRoute } from "astro";

export const prerender = true;

export const GET: APIRoute = ({ site }) => {
  const sitemapURL = new URL("sitemap-index.xml", site);
  const body = [
    "User-agent: *",
    "Allow: /",
    "",
    `Sitemap: ${sitemapURL.href}`,
  ].join("\n");

  return new Response(body, {
    headers: { "Content-Type": "text/plain; charset=utf-8" },
  });
};
