Markdown tradicional es el formato rey para la redacción técnica gracias a su simplicidad, portabilidad y legibilidad. Sin embargo, cuando se necesita presentar demostraciones interactivas, alertas dinámicas o gráficos de datos, el Markdown estándar se queda corto.

Aquí es donde entra **MDX**, un superconjunto de Markdown que permite incrustar sintaxis JSX y componentes de interfaz directamente en el cuerpo del documento.

## ¿Por qué MDX en Astro?

La integración oficial `@astrojs/mdx` permite compilar archivos `.mdx` utilizando el compilador de Astro. Esto desbloquea tres ventajas clave:

1. **Reutilización de Componentes de la Aplicación:** Podemos importar cualquier componente `.astro` o de un framework UI (React, Preact, Svelte) directamente en el contenido editorial.
2. **Interactividad Selectiva:** Al igual que en las páginas `.astro`, los componentes en MDX renderizan HTML puro por defecto a menos que se les aplique una directiva `client:*` (como `client:visible`).
3. **Mantenimiento Centralizado:** Si un componente de diseño o alerta se actualiza, todos los artículos que lo utilizan reflejan el cambio instantáneamente.

## Ejemplo de Componente Incrustado en MDX

A continuación, importamos un componente de enlace tipado directamente en el flujo del artículo:

import HeaderLink from '../../components/HeaderLink.astro';

<div style="margin: 1.5rem 0; padding: 1rem; border: 1px solid var(--color-border); border-radius: 0.5rem; background-color: var(--color-surface);">
  <p style="margin: 0 0 0.5rem 0; font-weight: 600;">Demostración interactiva en MDX:</p>
  <HeaderLink href="/proyectos/" style="display: inline-block; padding: 0.5rem 1rem; border-radius: 0.25rem; background-color: var(--color-brand); color: var(--color-text-inverse); text-decoration: none;">
    Explorar Catálogo de Proyectos →
  </HeaderLink>
</div>

## Casos de Uso Recomendados para MDX

* **Calculadoras interactivas:** Simuladores de costos, convertidores de unidades o demostraciones de algoritmos.
* **Alertas y Callouts tipados:** Avisos de seguridad, notas de versión o advertencias de breaking changes.
* **Visualizaciones de datos:** Gráficos SVG dinámicos o componentes de diagramas.

## Conclusión

MDX transforma la experiencia de lectura técnica de un documento estático pasivo a una **experiencia de aprendizaje interactiva**, manteniendo siempre la premisa de rendimiento y control de JavaScript en el cliente.
